# Блок «Начало» (start node)

## Цель

Добавить визуальный блок-маркер, однозначно определяющий точку входа в flow-диалог. Сейчас начало определяется неявно (ноды без входящих рёбер), что создаёт неоднозначность при наличии нескольких несвязанных групп блоков.

## Тип ноды

`start`

## Визуал

- Компактная нода с текстом «Начало»
- Зелёный цвет (green) — согласован с палитрой `colorClasses`
- Только выходной хэндл (source) внизу, без входного (target)
- Собственный компонент `StartNode.vue`

## Ограничения

- Ровно один на flow — не дублируется
- Не удаляется (Delete/Backspace игнорируются для этой ноды)
- Не копируется (Ctrl+C игнорируется для start-ноды)
- Не появляется в палитре `NodePalette`
- Клик выделяет ноду, но панель свойств справа не открывается

## Бэкенд

### Создание flow (`BotFlowController::store`)

Начальный граф меняется с пустого на:

```json
{
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "position": { "x": 250, "y": 50 },
      "data": {}
    }
  ],
  "edges": []
}
```

### Валидация (`UpdateBotFlowRequest`)

Добавить правило: в `graph.nodes` всегда должен присутствовать ровно один узел с `type: start`.

## Фронтенд

### Новые файлы

- `resources/js/Components/Flows/nodes/StartNode.vue` — компонент ноды с `defineOptions({ inheritAttrs: false })`, только source-хэндл

### Изменения в существующих файлах

- `blockTypes.js` — добавить `defaultBlockParams.start: {}`, НЕ добавлять в `flowNodeTypes` (палитра)
- `FlowCanvas.vue`:
  - Импорт и регистрация слота `#node-start`
  - Защита от удаления в `handleKeydown` — пропускать ноды с `type === 'start'`
  - Защита от копирования — исключать start-ноду из clipboard
- `NodePalette.vue` — без изменений (start не в палитре)
- `Edit.vue` — не открывать панель свойств при выделении start-ноды
